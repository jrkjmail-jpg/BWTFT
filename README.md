# BWTFT Telegram Bot

Telegram-бот для подготовки персонализированных детских книг:

- собирает свободное описание ребёнка;
- принимает фотографию;
- создаёт постоянный `character_prompt`;
- генерирует сказку на заданное число страниц;
- создаёт `scene_blueprints`;
- собирает финальные промпты для иллюстраций;
- показывает страницы через inline-меню.

## Быстрый старт

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
cp .env.example .env
```

Заполните `.env`, затем запустите:

```bash
bwtft-bot
```

## Деплой на Bot Hosting

Для хостинга, который запускает код из GitHub:

1. Укажите команду запуска:

```bash
python main.py
```

2. Добавьте переменные окружения:

```bash
TELEGRAM_BOT_TOKEN=...
OPENAI_API_KEY=...
OPENAI_TEXT_MODEL=gpt-4.1
OPENAI_VISION_MODEL=gpt-4.1
DATABASE_URL=sqlite+aiosqlite:///./data/bwtft.sqlite3
```

3. Если хостинг сам устанавливает зависимости, он может использовать `requirements.txt`.

## Сценарий

1. `/start`
2. Пользователь отправляет свободное описание ребёнка.
3. Пользователь загружает фото ребёнка.
4. Бот просит указать количество страниц, от 10 и больше.
5. Бот генерирует книгу и показывает меню страниц.

## Данные

SQLite-база создаётся автоматически. Основные сущности соответствуют ТЗ:

- `Book`
- `StoryPage`
- `SceneBlueprint`
- `CharacterPrompt`
- `StyleTemplate`
- `FinalPrompt`

Кнопка «Скопировать промпт» отправляет финальный промпт отдельным сообщением, удобным для копирования в Telegram.
